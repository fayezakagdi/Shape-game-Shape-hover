# Shapes Game

A simple interactive web project built with HTML and CSS featuring geometric shapes with hover effects.

## Features
* **Three Interactive Shapes:** Includes a Square, a Diamond, and a Circle.
* **Hover Color Transitions:** 
  * Hovering over the **Square (1)** turns it green.
  * Hovering over the **Diamond (2)** turns it red.
  * Hovering over the **Circle (3)** turns it aqua.
* **CSS Layout & Transforms:** Uses Flexbox for centering and CSS `rotate` transforms to create the diamond shape while keeping the inner text upright.

## Project Structure
* `index.html` – The main HTML structure containing the shape containers.
* `style.css` – Stylesheet handling layout, shape geometry, rotation, and hover states.

## How to Run
1. Download or clone this repository.
2. Open `index.html` in any web browser to view and interact with the shapes.
